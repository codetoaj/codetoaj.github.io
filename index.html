Megathil — Gamified Language-Learning Backend

Megathil is a gamified language-learning (Duolingo-style) backend REST API developed for the Tamil language. It manages users, auth/roles, courses, modules, units, topics and questions, plus a gamification layer (gems, trophies, badges, experience points, achievements). It also supports LMS-style tests, interviews, college/course/state/city lookup data, Razorpay payments, media uploads, certificates, contact/feedback forms and a dashboard.

  • Built the backend as a monolith of ~60 feature modules under a global /api base path with JWT auth
  • Implemented auth/roles and the gamification layer (gems, trophies, badges, XP, achievements)
  • Integrated Razorpay payments, Twilio SMS, Nodemailer email and Firebase push notifications
  • Set up media uploads (S3/Cloudinary), certificate generation, Swagger docs and Jest + Supertest tests
Technologies used
Framework: NestJS 10 (Node.js, TypeScript)
Database: MongoDB via Mongoose 8
Auth: Passport (JWT + local), bcrypt
Payments: Razorpay
Messaging/Email: Twilio (SMS), Nodemailer + @nestjs-modules/mailer
Files/Media: Multer (S3, Cloudinary), aws-sdk, canvas, qrcode, html-pdf, xlsx, json2xls, csv-parser
Notifications: Firebase Admin (push), @nestjs/schedule (cron)
API docs & Tests: Swagger (/api-docs), Jest + Supertest
Infra: Docker, ESLint/Prettier

  • Implemented athlete KPI calculation for performance tracking and analysis
