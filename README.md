# Amalan Jenicious F

Personal portfolio of **Amalan Jenicious F**, a Computer Science Engineer and Team Lead specializing in fullstack development (Node.js, React, Spring Boot, Angular, TypeScript, and cloud).

**Live site:** [https://codetoaj.github.io/](https://codetoaj.github.io/)

## What’s here

This is the **GitHub Pages** deployment repo (default branch `master`). A push to `master` publishes the site. There is no CI, build step, or `package.json`.

| File | Role |
| --- | --- |
| `index.html` | Self-contained single-page portfolio (vanilla HTML, CSS, and JS; Google Fonts only) |
| `404.html` | Custom not-found page, styled to match the portfolio |
| `favicon.svg` | Site icon |
| `robots.txt` / `sitemap.xml` | Crawler hints |

The page includes Home, Skills, Experience, Projects, and Contact, plus a light/dark theme toggle.

## Local preview

Open `index.html` in a browser, or serve the folder with any static file server. There is nothing to install or compile.
